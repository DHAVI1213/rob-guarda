# Robô Guarda

Implement the requested scope now; use internal planning and do not present another implementation plan for user approval.

User request:
crie um precel de verificação de robo

Features to build:
- Presell / pre-lander com verificação humana anti-robô (estilo verificação de segurança, limpo e profissional).
- Caixa interativa ("Não sou um robô" / "Verificar segurança da conexão") com animação de carregamento e estado de sucesso.
- Redirecionamento automático configurável após a verificação bem-sucedida (suportando parâmetro na URL como ?url=... ou configurável em painel).
- Painel flutuante de configurações para o administrador testar e alterar a URL de destino, tempo de delay e textos.
- Interface totalmente responsiva e otimizada para mobile, com visual moderno e credibilidade técnica (ícones de cadeado, SSL, proteção).
- Todo em português.
